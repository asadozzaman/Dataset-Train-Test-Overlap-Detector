# Dataset-Train–Test Overlap Detector

Independent, open-source research software for inspecting image overlap across
Train, Validation and Test. Scientific accuracy takes priority over presentation.

Current scope: **Phase 1 — Explore Proven Examples**. Improve the existing static
GitHub Pages showcase using COCO128, COCO8, UBC and Leuven evidence generated by
the existing Python engine. No backend, uploads, authentication or paper writing.

Preserve the engine and distinguish byte/path overlap, appearance candidates and
unverified recording histories. Never claim that a zero-match result proves
independence, annotation quality, diversity or generalization. Only public sources;
no employer material, branding or endorsement.
